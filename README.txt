# My Places（スマホ用PWA）

## この版でできること
- 場所名・カテゴリー・メモを登録
- 日本国内の場所を検索して緯度経度を取得（OpenStreetMap Nominatim）
- 登録場所を地図上にピン表示（Leaflet / OpenStreetMap）
- 行きたい／訪問済みの切り替え
- キーワード検索、Googleマップで開く
- JSONバックアップの書き出し・読み込み
- 対応ブラウザでホーム画面へのインストール

## 重要：インストールにはHTTPSでの公開が必要
PWAとしてホーム画面に追加するには、このフォルダ一式をHTTPS対応の静的ホスティング（例：GitHub Pages、Netlify等）に配置してください。`index.html`だけを端末で直接開く方法では、Service Workerによるオフライン機能やインストールが動きません。

## Androidでの使い方
1. このフォルダをHTTPS対応ホスティングにアップロード
2. 発行されたURLをAndroidのChromeで開く
3. 「ホーム画面に追加」またはChromeメニューの「アプリをインストール」を選ぶ
4. ホーム画面のMy Placesアイコンから起動

## データについて
登録データは端末内のブラウザ localStorage に保存され、サーバーには送信しません。ブラウザデータを消去すると消えるため、定期的に「バックアップを書き出す」を利用してください。別端末とは自動同期しません。

## 外部サービス
- 地図タイル：OpenStreetMap
- 場所検索：Nominatim（利用ポリシーに従い、検索連打を避けてください）
- 地図表示ライブラリ：Leaflet（CDN）
- Googleマップ：登録場所をGoogleマップ検索で開くリンク

地図表示・場所検索にはインターネット接続が必要です。
